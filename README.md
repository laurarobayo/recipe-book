# Recipe Book

A Flask web app for saving and managing recipes.

## Tools Used
- Flask
- MongoDB
- Docker + Docker Compose
- Jenkins
- GitHub

## How to Run

### Prerequisites
- Docker & Docker Compose installed
- Git

### Clone the repo
git clone https://github.com/laurarobayo/recipe-book.git
cd recipe-book

### Start the app
docker compose up --build
Visit the app at http://localhost:5000

### Stop the app
docker compose down

## Features
- View all saved recipes
- Add a recipe with ingredients and instructions
- View a recipe
- Delete a recipe
- Edit a recipe
